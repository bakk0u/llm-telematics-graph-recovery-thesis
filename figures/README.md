# Figures

This folder contains thesis-facing figures used by `main.tex`.

- `constructor_logo.jpeg`: title-page logo.
- `Ground_Truth_UC_Tesla_Energy_Consumption.png`: six-edge Tesla EV reference graph.
- `evaluation_matrix_tesla_ev_heatmap.png`: metric heatmap for the validated model-strategy cells.
- `f1_strategy_vs_model_tesla_ev.png`: F1 comparison across models and prompt strategies.
- `evaluation_per_llm_tesla_ev.png`: supplementary model-level result figure.

The script `scripts/generate_graph_recovery_figures.ps1` regenerates the graph-recovery figures from `results/tesla_ev_graph_recovery/`.
