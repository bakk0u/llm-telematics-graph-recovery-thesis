# Results

`tesla_ev_graph_recovery/` contains the validated graph-recovery artifact set used in the thesis.

Tracked artifacts include:

- evaluation matrices in wide and long CSV format;
- the signed ground-truth graph and adjacency matrix;
- per-model and per-strategy JSON sidecars;
- predicted adjacency matrices;
- graph visualizations;
- parsed edge exports and consensus-edge tables.

The thesis treats this folder as fixed evidence. New reruns should be saved separately and documented before replacing these validated artifacts.
